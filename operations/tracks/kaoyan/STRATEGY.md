# 考研主动学习与知识体系建设策略 V2

## 事实边界

按以下顺序处理冲突：用户当前纠正 → 实际记录 → 已接受复盘或决定 → 已接受计划与目标 → 派生状态 → 仪表盘或推断。

- Plan 只描述未来安排。
- Record 只保存用户明确报告的实际事实。
- State 是派生视图，不是独立证据。
- Topic 保存可复用知识，不保存个人学习进度。
- 目录和资料存在不代表已经阅读；看完或听懂不代表掌握。

## 核心目标

第一轮同时建立知识体系、解题能力和考试能力：

```text
完整走通知识地图
→ 理解核心概念和基本机制
→ 掌握基础方法
→ 完成章节基础题验证
→ 建立后续强化所需的知识定位能力
```

第一轮不追求解决所有综合难题，也不以课程观看数量作为完成标准。

## 资料与知识地图

- 数学一高等数学以 2027 武忠祥《高数基础篇》目录为知识地图；线性代数和概率论在确认主讲义目录后加入。
- 英语一语法与长难句以 2027 田静《句句真研》英语一目录为知识地图；真题承担阅读、翻译、完形和新题型训练。
- 408 数据结构以王道《2027 数据结构》目录为知识地图，后续按对应的 2027 王道复习指导目录推进。

课程视频不作为每日主线。只有自主阅读和对话讲解后仍无法理解时，才按具体知识点定向观看；之后必须回到讲义、对话或题目验证。

## 单个知识单元

每个单元统一执行：

```text
定位
→ 用户自主阅读
→ 定向回补必要前置
→ 用户表达理解和疑问
→ GPT 追问、纠错并只处理当前缺口
→ 必要时定向观看课程
→ 例题和章节题验证
→ 错题归因、独立重做和同类迁移
→ 更新状态并安排复测
```

默认不长篇灌输，也不立即公布完整答案。

## 三张地图

每科随真实学习逐点维护，不提前创建空地图：

- 知识地图：章节、小节、核心概念、前置知识、后续应用和节点联系。
- 考试地图：考试范围、题型、频率、第一轮要求和投入价值。
- 能力地图：解释、识别题型、选择方法、独立计算或推演、识别边界和迁移的实际表现。

高频、重点和偏点依次依据正式大纲和近十年真题、主流成熟资料共同判断、权威教材、GPT 分析。证据不足时标记“暂定”。

## 掌握等级

| 等级 | 可观察标准 | 后续动作 |
|---|---|---|
| A：已掌握 | 能独立解释和完成基础、常规题，说明适用条件，间隔复测仍能完成 | 正常复测 |
| B：基本掌握 | 概念基本清楚，基础题大部分能做，复杂条件下仍会犹豫 | 安排复测，稳定后推进 |
| C：初步理解 | 阅读或听讲能理解，独立做题仍不会 | 安排回补，不作为已掌握 |
| D：未掌握 | 核心概念不清，不能说明考点 | 重新学习或回补前置，不直接跳过 |

只有主动输出、题目验证和间隔复测支持的 A 或稳定 B 才允许正常推进。

## 每日计划

生成每日计划前读取 Goal、Strategy、State、当前已接受计划、最近 Records、最近 Review 和相应主讲义目录。

每项任务必须包含：

1. 当前地图位置；
2. 当天讲义范围；
3. 自主阅读目标；
4. 需要回答的问题或主动输出；
5. 对应练习范围和训练量；
6. 完成标准；
7. 预计时间；
8. 最低完成线。

具体页码只能来自实际版本；无法确认时写章节或小节。阶段或周计划不得预先固定每日任务。

## 学科差异

- 数学一：讲义概念和推导 → 对话理解 → 例题复现 → 基础题训练 → 题型识别；保留纸笔计算和完整推导。
- 英语一：讲义词汇或句法 → 真题句子验证 → 结构分析 → 自然翻译 → 阅读或表达迁移。
- 408：复习指导阅读 → 准确定义 → 机制和数据变化推演 → 选择题边界判断 → 算法或计算题验证。

## 反馈与调整

反馈只记录用户明确提供的内容、题量、正确率、用时、卡点和状态。根据证据更新 State，并只调整未来 1～7 天；不得机械堆积延期任务。

犯困、回避、没有思路或任务过大时，立即缩小为：阅读一个定义 → 用自己的话解释 → 完成一道最基础的题。
