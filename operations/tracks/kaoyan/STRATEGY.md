# 考研执行策略

## 事实边界

按以下顺序处理冲突：用户当前纠正 → 实际记录 → 已接受复盘或决定 → 已接受计划与目标 → 派生状态 → 仪表盘或推断。

- Plan 描述未来安排。
- Record 只保存明确报告的实际事实。
- State 从计划、记录和复盘派生，不是独立证据。
- Topic 保存可复用知识，不保存个人学习进度。
- 未报告的信息保持未知，不按零、未完成或已掌握处理。

## 学习闭环

知识定位 → 主动理解 → 独立输出 → 题目验证 → 错误反馈。

课程、讲义和教材只是输入来源，不以视频完成率或章节播放进度判断掌握。

## 今日计划

生成今日计划前依次读取：目标、策略、当前状态、最新已接受计划、最近记录、最近复盘和对应 Topic。

每项任务必须包含：

- 计划内任务 ID；
- 知识节点；
- 使用材料；
- 预计时间；
- 主动输出；
- 训练量；
- 完成标准；
- 最低完成线；
- 明确时使用 Hub 相对知识链接。

100% 是当天目标，60% 是最低完成线，80%～100% 是正常稳定范围。

## 时间优先级

正常顺序：上班碎片时间推进 408 → 晚间优先数学一 → 英语每日不断档 → 机动补课与复盘。

时间不足时依次保留：

1. 数学一核心学习时间；
2. 英语一最低积累；
3. 将 408 新课缩为复习或少量选择题；
4. 不通过熬夜机械补回全部欠账。

## 学科方法

### 数学一

讲清定义原因、推导依据、题型识别、适用条件和常见错误。默认先给突破口或一个提示，不立即公布完整答案。重点训练“题目条件 → 类型识别 → 方法选择 → 完成计算”。

### 英语一

句子分析顺序：主干 → 从句关系 → 修饰成分 → 逻辑关系 → 自然中文含义。词汇进入真题语境，并通过朗读、造句、改述或复述形成输出。

### 408

准确区分教材定义、408 判定标准和工程经验；跟踪机制、执行过程、状态、数据和边界条件；重视计算步骤及选择题陷阱。

## 最低完成线

状态较差时，把任务缩小到一个可验证动作：

- 数学一：学习 20 分钟，并独立完成 2 道基础题。
- 英语一：精读 1 个长难句，并复习 10～20 个语境词汇。
- 408：学习 1 个小考点，并完成 5 道选择题。

先判断卡点属于概念、题意、计算、思路、真实疲劳还是畏难回避；一次只解决一个小问题。

## 反馈与调整

学习反馈仅记录用户明确提供的内容、题量、正确率、用时、卡点和状态。根据证据更新派生状态，并只调整未来 1～7 天；不得机械堆积延期任务。

每周复盘检查实际记录、计划偏差、重复错误、掌握质量和时间偏差。重大目标、长期计划、掌握判断或科目优先级变化必须先形成 Proposal，确认后应用。
