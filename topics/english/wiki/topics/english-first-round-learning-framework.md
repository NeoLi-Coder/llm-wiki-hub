# 英语一第一轮学习框架

## 摘要

英语一第一轮不是先背完单词、学完语法再开始阅读，而是同步训练语言理解和应试判断。核心链路是：词汇与句法基础 → 句子和段落理解 → 真题阅读 → 证据与干扰项分析 → 翻译、写作和口头输出。

## 第一轮目标

- 核心词汇能够在语境中识别，而不只记住单一中文释义。
- 普通长难句能够按固定顺序独立拆解。
- 阅读题能够定位原文证据，并说明主要干扰项错在哪里。
- 翻译和写作完成基础启动。
- 真题材料能够用于朗读、改述和简短复述。

第一轮不以课程、单词书或真题年份的完成数量作为掌握证明。

## 两棵能力树

语言能力树回答“能不能读懂”：词汇 → 句法 → 长难句 → 段落逻辑 → 文章结构。

应试任务树回答“能不能得分”：题型识别 → 原文定位 → 证据匹配 → 干扰项排除 → 限时作答。

两棵树必须同步训练。只学语言可能读懂却选错；只学技巧则容易在文章变化后失效。

## 词汇训练

词汇分为三个层级：词形识别、语境理解和主动调用。大部分阅读词汇至少达到语境理解；少量高频写作词汇达到主动调用。

标准闭环：

1. 单词书负责初识。
2. 真题句子负责判断词性、语境词义、熟词僻义和搭配。
3. 间隔重复负责长期提取。
4. 少量高频表达通过造句、翻译、改写和口头表达进入主动词汇。

## 长难句训练

固定分析顺序：主干 → 从句关系 → 修饰成分 → 逻辑关系 → 自然中文含义。

评价标准不是看懂解析，而是能够独立找出谓语、主语、宾语、从句边界和关键逻辑。

## 阅读标准流程

1. 独立作答：不查词、不看解析，记录时间和犹豫题。
2. 证据分析：定位原文，说明正确项依据和错误项问题。
3. 语言回补：只处理影响理解的词汇、句法、搭配和逻辑词。
4. 结构复盘：概括段落作用、文章主旨和作者态度。
5. 间隔重做：检查是否仍能定位证据并避开同类错误。

常见错误包括词汇缺失、熟词僻义、句法、段落逻辑、主旨、定位、证据匹配、干扰项、过度推断和时间压力。

## 输出协同

口语不另起庞大体系，而是嵌入现有材料：学完搭配后造句，拆完长句后朗读和改述，精读段落后用一至三句话复述。写作则从高频表达、中译英和单段表达逐步过渡到自己的作文框架。

## 困难处理

遇到过难材料时，按“整篇 → 段落 → 句子 → 主干”缩小任务，先完成一个可验证动作，再恢复原任务。
