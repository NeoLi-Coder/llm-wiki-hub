# 数学一第一轮复习路线 V1.0

## 一、第一轮复习总体目标

第一轮复习目标不是完整学完教材，而是：

> 建立数学地图 → 掌握核心概念 → 建立基础题型能力 → 初步接触真题

核心任务：

1.  建立数学知识体系。
2.  掌握基础和常规题型。
3.  建立题目条件到解题方法之间的转换能力。
4.  为后续强化阶段打基础。

第一轮结束标准：

不是所有章节全部精通，而是：

> 基本知识体系建立，80%左右基础题和常规题能够独立完成。

------------------------------------------------------------------------

# 二、第一轮学习流程

## 阶段1：章节定位（10%时间）

目标：

建立章节地图。

需要明确：

-   本章研究什么。
-   与前后章节有什么关系。
-   在考试中的作用。
-   常见考查方式。

例如：

导数学习前，需要理解：

函数 → 极限 → 连续 → 导数

导数解决：

-   变化率问题。
-   单调性问题。
-   极值和最值问题。

------------------------------------------------------------------------

## 阶段2：核心概念理解（30%时间）

重点：

理解：

-   定义。
-   公式来源。
-   使用条件。

不要一开始追求所有证明细节。

重点回答：

-   为什么这样定义？
-   这个知识解决什么问题？
-   什么情况下使用？

------------------------------------------------------------------------

## 阶段3：基础题训练（40%时间）

这是第一轮核心。

目标：

形成基础操作能力。

训练内容：

-   教材例题。
-   基础习题。
-   章节训练题。

每道典型题总结：

1.  题目特征。
2.  解题入口。
3.  使用方法。

------------------------------------------------------------------------

## 阶段4：章节复盘（20%时间）

完成：

-   错题整理。
-   方法总结。
-   知识结构回忆。

要求：

脱离资料，可以说明：

-   本章研究什么。
-   核心方法有哪些。
-   常见题型如何处理。

------------------------------------------------------------------------

# 三、章节学习顺序设计

学习顺序采用：

> 基础依赖关系 + 考试价值 + 学习反馈

综合确定。

------------------------------------------------------------------------

# 第一模块：高等数学基础

## 1. 函数

优先级：

★★★★★

重点：

-   函数概念。
-   定义域。
-   奇偶性。
-   单调性。
-   复合函数。

作用：

建立后续极限、导数、积分学习基础。

------------------------------------------------------------------------

## 2. 极限

优先级：

★★★★★

重点：

-   极限概念。
-   极限计算。
-   等价无穷小。
-   洛必达法则。
-   两个重要极限。

作用：

连接连续、导数、积分。

------------------------------------------------------------------------

## 3. 连续

优先级：

★★★★☆

重点：

-   连续定义。
-   间断点判断。
-   连续性质。

------------------------------------------------------------------------

## 4. 一元函数微分学

优先级：

★★★★★

重点：

-   导数定义。
-   求导方法。
-   微分。
-   单调性。
-   极值。
-   最值。
-   函数图像分析。

这是数学一核心章节。

------------------------------------------------------------------------

## 5. 一元函数积分学

优先级：

★★★★★

重点：

-   不定积分。
-   定积分。
-   积分计算。
-   面积问题。
-   积分应用。

建立：

导数（变化） → 积分（累积）

的完整体系。

------------------------------------------------------------------------

# 第二模块：线性代数

线性代数体系相对独立，可以穿插学习。

学习顺序：

矩阵

↓

行列式

↓

向量

↓

线性方程组

↓

特征值

↓

二次型

重点：

理解矩阵和线性关系，而不是只记计算步骤。

------------------------------------------------------------------------

# 第三模块：概率论

学习顺序：

随机事件

↓

随机变量

↓

概率分布

↓

数字特征

↓

参数估计

重点：

建立概率模型能力。

------------------------------------------------------------------------

# 四、第一轮每日学习结构

推荐数学学习时间：

每天3～4小时。

结构：

## 1. 知识理解（约40分钟）

内容：

-   看课程。
-   阅读教材。
-   整理知识框架。

------------------------------------------------------------------------

## 2. 基础训练（约90分钟）

内容：

-   例题。
-   基础题。
-   章节练习。

------------------------------------------------------------------------

## 3. 错题复盘（约40分钟）

分析：

-   为什么错。
-   正确方法是什么。
-   下次如何识别。

------------------------------------------------------------------------

## 4. 知识回忆（约20分钟）

脱离资料总结：

-   今天学习了什么。
-   解决什么问题。
-   常见方法是什么。

------------------------------------------------------------------------

# 五、第一轮禁止事项

## 1. 不追求一次完全掌握

数学理解具有递进性。

第一次掌握60%～70%即可。

后续通过：

做题 → 暴露问题 → 回补知识

逐步完善。

------------------------------------------------------------------------

## 2. 不长时间被动听课

学习流程：

输入 → 输出 → 反馈

不能停留在听懂阶段。

------------------------------------------------------------------------

## 3. 不提前大量挑战难题

第一轮目标：

建立知识和题型模型。

------------------------------------------------------------------------

# 六、章节复盘标准

每章结束，需要回答：

## 知识层面

-   这一章研究什么？
-   核心公式有哪些？
-   使用条件是什么？

## 方法层面

-   常见题型有哪些？
-   如何识别？
-   应该使用什么方法？

## 问题层面

-   哪些内容仍然不会？
-   是否影响后续学习？

------------------------------------------------------------------------

# 七、第一轮路线总结

整体路线：

建立数学地图

↓

学习核心概念

↓

完成基础训练

↓

形成题型认识

↓

章节复盘

↓

进入下一模块

最终目标：

看到一道基础或中档题时：

知道它属于哪个知识模块，并知道解决方向。

避免：

教材看完，但不会做题。
