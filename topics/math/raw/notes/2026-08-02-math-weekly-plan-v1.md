# 数学一第一轮详细周计划（2026年8月1日—12月31日）V1.0

## 一、使用说明

- 本计划严格使用每周16小时数学额度，不挤占英语、408和政治时间。
- 题量以所选讲义和配套基础题册为准；课堂例题不计入新题量。
- 每道题独立思考至少5分钟；仍无入口时再看提示，并记录卡点。
- 周日只根据周测结果修补一个最关键问题，不因低分整周重学。
- 课程版本不同，按下列同名主题匹配对应课次。

## 四、执行偏差处理

| 情况 | 唯一处理方式 |
|---|---|
| 单日少学30分钟以内 | 不补时长，次日照常执行 |
| 单日任务未完成 | 保留2道代表题和1条错因，其余进入周五处理 |
| 单周实际时间不足12.8小时 | 下一周减少20%新题量，不减少主线课程 |
| 周测正确率60%～69% | 下一周周五回补1个核心点 |
| 周测正确率低于60% | 回补前置知识，下一周新内容仍保留70% |
| 连续两周低于60% | 暂停增加题量，重新检查资料难度和听课/做题比例 |
| 遇到偏题、怪题或高难证明 | 标记为第二轮候选，不在第一轮消耗超过20分钟 |
