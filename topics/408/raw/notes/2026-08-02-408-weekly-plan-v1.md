## 二、正常周固定执行结构

### 2.1 时间结构

| 日期 | 时间 | 任务性质 |
|---|---:|---|
| 周一 | 1.5小时 | 新知识A：输入、主动输出、基础验证 |
| 周二 | 1.5小时 | 新知识A巩固或新知识B |
| 周三 | 1.5小时 | 新知识B：机制、计算或算法 |
| 周四 | 1.5小时 | 新知识B巩固、边界条件和配套题 |
| 周五 | 1.5小时 | 闭卷回忆、错题复做、章节结构整理 |
| 周六 | 1小时 | 章节习题或代表性综合题 |
| 周日 | 1.5小时 | 周测、订正、掌握分级和下周调整 |
| **合计** | **10小时** | — |

### 2.2 单次1.5小时学习模板

```text
5分钟：明确知识节点和完成标准
→ 35～40分钟：课程或复习指导输入
→ 15～20分钟：合上材料主动复述、画图或推演
→ 25～30分钟：基础题和常规题
→ 5～10分钟：记录错误原因和掌握等级
```

课程过长时，只学习当前知识节点对应部分，不以视频结束位置作为当天完成标准。

### 2.3 周完成标准

正常周至少形成以下产出：

- 一张本周章节结构图或流程图；
- 一次闭卷口头解释或书面重建；
- 25～40道章节选择题；
- 2～5道计算题、算法题或综合题；
- 一次周测与错题归因；
- 本周知识节点A/B/C/D掌握分级。

题量可根据科目和题目难度调整，不能用题量代替掌握质量。

## 三、延期和动态调整规则

### 3.1 每日完成率

- 100%：完成当天计划；
- 60%：最低完成线；
- 60%～99%：允许，但未完成部分必须进入周内调整；
- 低于60%：记录真实原因，次日不机械叠加全部欠账。

### 3.2 单周完成率低于80%

```text
保留高频主干
→ 删除重复性低价值记录
→ 周末回补一个最大缺口
→ 其余转入阶段薄弱清单
→ 主线继续推进
```

### 3.3 连续两周低于80%

检查：

- 上班碎片时间是否真实可用；
- 课程占比是否过高；
- 是否大量抄笔记；
- 单日知识节点是否过大；
- 是否在难题上停留过久；
- 是否存在畏难回避。

调整顺序：

```text
减少抄写
→ 压缩课程
→ 保留主动输出
→ 保留基础题
→ 降低单日新内容
→ 不取消周测和复盘
```

### 3.4 阶段延期上限

单科最多借用下一阶段2～3天收口核心内容，不整体顺延全部计划，不通过熬夜追赶，不大量挤占数学和英语时间。
