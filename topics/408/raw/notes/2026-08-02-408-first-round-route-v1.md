# 408第一轮复习路线_V1.0

> 适用目标：电子科技大学计算机专业硕士初试，408目标分数100～110分。  
> 执行周期：2026年8月1日—2026年12月31日。  
> 时间预算：每周约10～10.25小时，总投入约220小时。  
> 上位规则：《408学习体系设计_V1.0》《考研学习方法指导方针_V1.0》《考研长期执行机制与心理建设_V1.0》。  
> 文档定位：规定第一轮“按什么顺序推进、每个阶段达到什么水平、如何验收和调整”；不替代逐周、逐日任务表。

---

## 一、路线设计依据

### 1.1 考试结构

本路线以目前公开的2026版408考试大纲结构为基线：

| 科目 | 分值 | 占408总分 |
|---|---:|---:|
| 数据结构 | 45分 | 30.0% |
| 计算机组成原理 | 45分 | 30.0% |
| 操作系统 | 35分 | 23.3% |
| 计算机网络 | 25分 | 16.7% |
| **合计** | **150分** | **100%** |

现行题型结构为：

- 单项选择题：80分；
- 综合应用题：70分；
- 考试时间：180分钟。

因此第一轮不能只背概念，也不能只刷选择题，必须同步建立：

```text
概念判定
→ 机制推演
→ 计算与算法
→ 综合应用
```

2027正式考试大纲发布后，需核对知识点增删和表述变化；若主体结构未变，只调整局部内容，不推翻本路线。

### 1.2 个人条件

当前具备计算机科班和开发经验，但第一轮仍按完整体系学习，原因是：

- 工程中会使用，不等于能按教材定义准确判定；
- 熟悉Java、数据库、网络开发，不等于掌握408计算和边界条件；
- 部分内容有直觉优势，但应试知识可能存在断点；
- 目标是稳定取得100～110分，需要四科主干完整，不能依靠单科优势补偿明显短板。

### 1.3 路线总原则

第一轮采用单科集中推进：

```text
数据结构
→ 计算机组成原理
→ 操作系统
→ 计算机网络
→ 四科串联与收口
```

不在同一天频繁切换四门课程。

选择这一顺序的原因：

1. 数据结构更接近已有编程经验，适合作为启动科目，先建立稳定执行感。
2. 组成原理提供指令、CPU、存储和I/O基础，是理解操作系统底层机制的重要前置。
3. 操作系统建立在硬件执行、存储和中断机制之上。
4. 计算机网络相对独立，放在最后集中建立端到端通信体系。
5. 最后统一串联程序、CPU、操作系统、I/O和网络完整链路。

## 二、第一轮的核心目标

第一轮完成不等于“课程和教材看完”，而是形成可继续强化的基础能力。

截至2026年12月31日，应达到：

### 2.1 知识框架

- 完成四科全部主干章节第一遍学习；
- 能说清每章解决的问题、前置知识和后续联系；
- 每科形成一张可闭卷重建的知识总图。

### 2.2 概念与机制

- 高频概念能够脱离材料解释；
- 关键流程能够通过结构图、状态图、时序图或表格推演；
- 能区分相似概念及其适用边界。

### 2.3 计算与算法

- 数据结构基础算法能够读懂、推演并写出主要步骤；
- 组成原理常规计算能够按标准流程完成；
- 操作系统调度、PV、死锁、地址转换等基础题能够独立处理；
- 计算机网络子网、路由、TCP等基础计算能够独立处理。

### 2.4 做题能力

- 章节选择题正确率达到可进入第二轮的水平；
- 综合题能识别考点、列出主要步骤；
- 重要错题完成错误归因和至少一次复测；
- 形成第二轮薄弱章节和高频错误清单。

第一轮不要求：

- 所有难题一次做对；
- 冷门细节全部背熟；
- 综合题达到完整限时高分；
- 为了追求章节满分而延误整体主线。

# 第一阶段：启动诊断

## 四、时间

**2026年8月1日—2026年8月2日**

## 五、阶段目标

启动阶段只完成三件事：

1. 统一资料；
2. 建立当前水平基线；
3. 确定最初薄弱点。

禁止因为诊断结果较低而临时增加大量课程或重写整个计划。

## 六、执行内容

### 6.1 资料统一

保留唯一主线资料：

- 王道课程；
- 王道复习指导；
- 王道配套习题；
- 一套错题与复盘记录；
- 真题资料。

补充教材或文章只用于解决具体难点，不同时维护多套同类笔记。

### 6.2 基础诊断

完成约30道四科混合基础题，只判断：

- 哪些概念完全陌生；
- 哪些内容有印象但不会做题；
- 哪些内容因工程经验产生错误判断；
- 四科相对强弱。

诊断分数不作为能力结论。

### 6.3 建立错误标签

至少建立以下标签：

```text
知识缺失
概念混淆
机制断裂
题型识别错误
方法选择错误
计算错误
审题错误
畏难放弃
```

## 七、启动验收

启动阶段完成标准：

- 资料入口唯一；
- 建立408总目录；
- 记录每科不超过5个初始薄弱点；
- 完成第一批诊断题；
- 正式进入数据结构主线。

# 第二阶段：数据结构

## 八、时间

**2026年8月3日—2026年9月13日，共6周**

## 九、阶段定位

数据结构是第一轮的启动科目，也是408算法能力的基础。

学习主线：

```text
逻辑结构
→ 存储结构
→ 基本操作
→ 算法执行过程
→ 时间与空间复杂度
→ 适用边界
```

不能只记结论和复杂度，必须能够手工推演结构变化。

## 十、模块顺序

### 第1周：线性表

核心内容：

- 线性表基本概念；
- 顺序表；
- 单链表、双链表、循环链表；
- 插入、删除、查找；
- 顺序与链式存储对比。

阶段输出：

- 能画出插入和删除后的结构；
- 能解释基本操作复杂度；
- 能处理空表、首结点、尾结点等边界。

### 第2周：栈、队列、数组与串

核心内容：

- 栈和队列的操作限制；
- 循环队列；
- 双端队列；
- 栈的典型应用；
- 特殊矩阵压缩存储；
- 串与模式匹配、KMP基本过程。

阶段输出：

- 能手工推演入栈、出栈和队列变化；
- 能判断循环队列队满、队空条件；
- 能解释KMP失配后的移动依据。

### 第3周：树与二叉树

核心内容：

- 树和二叉树基本性质；
- 遍历；
- 线索二叉树；
- 树、森林与二叉树转换；
- 哈夫曼树和哈夫曼编码。

阶段输出：

- 能根据遍历序列还原基础结构；
- 能手算各种遍历；
- 能完成哈夫曼构造与编码计算；
- 能区分结点度、树高、层次等概念。

### 第4周：图

核心内容：

- 图的基本概念与存储；
- BFS和DFS；
- 最小生成树；
- 最短路径；
- 拓扑排序；
- 关键路径。

阶段输出：

- 能依据邻接矩阵或邻接表推演遍历；
- 能逐步执行Prim、Kruskal、Dijkstra等算法；
- 能判断有向无环图、拓扑序和关键活动。

### 第5周：查找

核心内容：

- 顺序查找和折半查找；
- 分块查找；
- 二叉排序树；
- 平衡二叉树；
- B树、B+树；
- 散列表；
- 平均查找长度。

阶段输出：

- 能计算基础平均查找长度；
- 能完成查找树的插入、删除和调整过程；
- 能比较不同查找结构的适用条件；
- 能理解B树、B+树与数据库索引的教材模型差异。

### 第6周：排序与数据结构收口

核心内容：

- 插入、交换、选择、归并、基数排序；
- 每趟排序结果；
- 稳定性；
- 时间、空间复杂度；
- 是否原地；
- 数据结构阶段综合测试。

阶段输出：

- 能根据中间序列判断排序算法；
- 能比较不同排序方法；
- 能解释稳定性和原地性；
- 能完成一轮数据结构知识图。

## 十一、训练重点

数据结构每个算法统一完成：

```text
解决什么问题
→ 数据怎样组织
→ 每一步怎样变化
→ 为什么正确
→ 复杂度从哪里产生
→ 边界条件是什么
```

算法题第一轮要求：

- 能读懂标准算法；
- 能写出核心伪代码；
- 能说明循环、递归或指针变化；
- 能处理基础边界；
- 不追求复杂创新算法。

## 十二、数据结构阶段验收

进入组成原理前，应满足：

- 主干章节完成率不低于80%；
- 高频知识至少达到B级；
- 章节选择题总体正确率达到70%左右；
- 能独立完成基础遍历、查找、排序和复杂度分析；
- 至少完成一次数据结构阶段测试；
- 形成不超过5项的第二轮薄弱点。

若阶段测试低于60%：

```text
定位失分最多的两个模块
→ 各补一次主动输出
→ 各完成5～10道基础题
→ 主线进入组成原理
```

不得因一个章节未完全掌握而无限延长数据结构阶段。

# 第三阶段：计算机组成原理

## 十三、时间

**2026年9月14日—2026年10月18日，共5周**

## 十四、阶段定位

组成原理的核心不是背硬件名词，而是理解：

```text
数据怎样表示
→ 指令怎样形成
→ CPU怎样执行
→ 存储怎样提供数据
→ I/O怎样交换数据
```

本阶段是第一轮计算题和整机概念建立的关键阶段。

## 十五、模块顺序

### 第7周：数据表示与运算

核心内容：

- 进制和编码；
- 定点数、补码；
- 浮点数；
- 算术运算；
- 溢出判断；
- 校验码基础。

阶段输出：

- 能稳定转换进制；
- 能解释补码运算规则；
- 能按位数完成浮点数和溢出计算；
- 所有计算写明单位、位数和符号含义。

### 第8周：存储系统

核心内容：

- 存储器层次；
- 主存组织；
- 字扩展和位扩展；
- Cache映射、替换与写策略；
- 虚拟存储器的硬件基础。

阶段输出：

- 能区分地址位数、数据位数和容量；
- 能划分Cache地址字段；
- 能计算命中率与平均访问时间；
- 能解释局部性原理。

### 第9周：指令系统

核心内容：

- 指令格式；
- 操作码扩展；
- 寻址方式；
- CISC和RISC；
- 程序与机器指令之间的基础关系。

阶段输出：

- 能根据指令格式计算字段位数；
- 能判断有效地址和操作数来源；
- 能区分常见寻址方式；
- 能从程序语句理解指令层面的基本操作。

### 第10周：CPU与流水线

核心内容：

- CPU基本结构；
- 数据通路；
- 指令周期；
- 控制器；
- 单周期与多周期；
- 流水线；
- 数据、控制和结构冒险。

阶段输出：

- 能跟踪取指、间址、执行和中断过程；
- 能画出基础数据通路；
- 能计算流水线时间、吞吐率和加速比；
- 能判断冲突及处理方式。

### 第11周：总线、I/O与组成原理收口

核心内容：

- 总线结构与定时；
- 总线性能；
- 程序查询；
- 中断；
- DMA；
- 组成原理综合测试。

阶段输出：

- 能比较查询、中断和DMA的数据路径；
- 能判断CPU、主存、设备之间的控制关系；
- 能完成带宽、周期和传输时间计算；
- 能形成“程序到硬件执行”的知识图。

## 十六、训练重点

组成原理计算题固定执行：

```text
写已知量与单位
→ 判断求解对象
→ 画地址或数据结构
→ 选择公式
→ 分步计算
→ 检查位数、数量级和边界
```

禁止只记公式。每个公式必须明确：

- 各变量含义；
- 单位；
- 使用条件；
- 题目中哪些信息决定取值。

## 十七、组成原理阶段验收

进入操作系统前，应满足：

- 能解释一条指令从取指到执行的基本过程；
- 数据表示、Cache、指令、流水线等基础题能够独立完成；
- 章节选择题总体正确率达到65%～70%；
- 综合题能够列出主要结构和计算步骤；
- 完成一次组成原理阶段测试；
- 形成不超过5项的第二轮薄弱点。

若计算题频繁错误，优先判断：

```text
概念不清
→ 地址结构不会画
→ 单位错误
→ 公式条件错误
→ 纯计算失误
```

根据真实原因回补，不通过重复看整章课程解决。

# 第四阶段：操作系统

## 十八、时间

**2026年10月19日—2026年11月22日，共5周**

## 十九、阶段定位

操作系统的核心是跟踪：

```text
谁在运行
→ 谁在等待
→ 资源属于谁
→ 状态为什么变化
→ 地址如何转换
→ 数据如何进入文件和设备
```

学习时必须把静态概念转化为状态变化过程。

## 二十、模块顺序

### 第12周：进程、线程与处理机调度

核心内容：

- 操作系统基本概念；
- 进程和线程；
- PCB；
- 状态转换；
- 上下文切换；
- 调度层次与调度算法；
- 周转时间、响应时间等指标。

阶段输出：

- 能闭卷画进程状态图；
- 能说明每条状态转换的触发事件；
- 能用时间轴推演调度；
- 能计算常见调度指标。

### 第13周：同步互斥与死锁

核心内容：

- 临界资源和临界区；
- 信号量；
- PV操作；
- 经典同步问题；
- 死锁条件；
- 预防、避免、检测和解除；
- 银行家算法。

阶段输出：

- 能先分析同步关系，再写PV；
- 能判断信号量初值；
- 能推演进程阻塞与唤醒；
- 能判断安全状态和死锁条件。

### 第14周：内存管理

核心内容：

- 连续分配；
- 分页、分段、段页式；
- 地址转换；
- TLB；
- 虚拟内存；
- 页面置换；
- 抖动和工作集基础。

阶段输出：

- 能分解逻辑地址；
- 能完成页表、段表和TLB地址转换；
- 能手算页面置换过程和缺页次数；
- 能区分虚拟地址、物理地址和存储容量。

### 第15周：文件系统

核心内容：

- 文件逻辑结构与物理结构；
- 文件分配方式；
- 目录；
- 文件控制块；
- 空闲空间管理；
- 文件系统实现。

阶段输出：

- 能比较连续、链接和索引分配；
- 能根据文件大小计算索引结构；
- 能说明目录查找过程；
- 能区分文件逻辑结构和物理结构。

### 第16周：I/O管理与操作系统收口

核心内容：

- I/O控制方式；
- I/O软件层次；
- 缓冲；
- 设备分配；
