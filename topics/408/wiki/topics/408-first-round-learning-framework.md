# 408 第一轮学习框架

## 摘要

408 第一轮不是四本书和课程的简单完成清单，而是建立概念判定、机制推演、计算与算法、跨科关联和应试识别能力。学习结果必须能够通过闭卷解释、过程推演和题目验证。

## 第一轮目标

- 完成数据结构、组成原理、操作系统和计算机网络主干。
- 能说明每章解决的问题、前置知识和后续联系。
- 高频概念能够脱离材料准确解释。
- 关键流程能够用结构图、状态图、时序图或表格推演。
- 基础计算、常规算法和章节题能够独立处理。
- 重要错题完成归因和复测，并形成第二轮薄弱点。

## 主线顺序

数据结构 → 组成原理 → 操作系统 → 计算机网络 → 四科串联与收口。

这个顺序先利用编程基础启动，再建立硬件执行基础，随后理解操作系统资源管理，最后完成端到端通信链路。正常情况下不在同一天频繁切换四科。

## 统一学习闭环

知识定位 → 原理理解 → 主动推演 → 题目验证 → 错误归因 → 间隔复测。

每个知识点至少回答：它解决什么问题、对象如何组织、过程如何变化、为什么成立、适用条件是什么、边界在哪里、考试如何设陷阱。

## 分科学习重点

### 数据结构

跟踪逻辑结构、存储结构、基本操作、算法过程、复杂度和边界条件。算法题需要能读懂、手工推演并写出核心伪代码。

### 组成原理

沿“数据表示 → 指令 → CPU 执行 → 存储 → I/O”建立整机链路。计算题先写已知量和单位，再画地址或数据结构、分步计算并检查位数和数量级。

### 操作系统

跟踪运行者、等待者、资源归属、状态事件、地址转换和 I/O 链路。PV、调度、死锁和内存题先列对象、状态、资源与事件，再按时间推演。

### 计算机网络

沿封装、传输、路由、链路发送和接收端解封装建立完整通信链路。计算题明确主机、地址、端口、协议层和状态变化。

## 掌握证据

观看课程和读完章节不是掌握。有效证据包括：闭卷解释、独立画图、推演过程、基础题正确率、综合题步骤、错题复做和阶段测试。

工程经验可以辅助理解，但不能替代教材定义和 408 判定标准。
